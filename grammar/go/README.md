# Go grammar reference (frozen snapshot)

**Pinned source:** [Go Language Specification](https://go.dev/ref/spec) — language version **go1.26** (fetched 2026-07-25).

This directory is a **reference for inspiration**, not a compliance checklist.
Aram is Go-inspired and free to diverge.

| File | Role |
|------|------|
| `ebnf-notation.md` | Go’s EBNF operators (same style we use for Aram) |
| `ebnf-core.md` | Curated core productions useful while designing Tamil-0+ |
| Upstream | Full prose + all productions: https://go.dev/ref/spec |

Do not “fix” Go here. When Go’s spec changes, bump the pin deliberately and note it in `notes/design-decisions.md`.
