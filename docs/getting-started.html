Requirements

  • Linux (the current supported runtime target).
  • Go toolchain to build/run the Aram compiler.
  • GCC or Clang-compatible cc to compile generated C.
  • pthread support for concurrency and the runtime.
  • libdl (-ldl) for dynamic loading used by the SQL runtime.
  • For database programs: a runtime SQLite shared library such as libsqlite3.so.0 (Debian/Ubuntu: libsqlite3-0). Headers and -lsqlite3 are not required to build.
  • A UTF-8 editor with a Tamil font such as Noto Sans Tamil.

The repository includes a portable Go setup helper:

source tools/env.sh
go test ./...

If your system Go is suitable, the first line is optional.

Run the compiler

The compiler entry point is cmd/aram. During development, invoke it through Go:

go run ./cmd/aram check corpus/tamil/வணக்கம்.aram
go run ./cmd/aram run corpus/tamil/வணக்கம்.aram
go run ./cmd/aram build corpus/tamil/வணக்கம்.aram
CommandBehavior
runParse, typecheck, emit C, compile, and execute. This is the default command.
buildParse, typecheck, emit C, and compile without execution.
emitWrite generated C only.
checkParse and typecheck, then print ok.
parsePrint a short AST summary.
lexPrint the token stream.

Generated C builds use -O2 by default. Select a different level or debug output explicitly:

go run ./cmd/aram build --debug program.aram
go run ./cmd/aram build -O0 program.aram
go run ./cmd/aram build -O3 -o bin/my-program program.aram

Supported optimization flags are -O0, -O1, -O2, -O3, and -Os. Without -o, outputs are written below build/.

Your first program

Create hello.aram:

தொகுப்பு தொடக்கம்

செயல்பாடு தொடக்கம்() {
    பதிப்பி("வணக்கம், உலகம்!")
}

A runnable package follows the entry convention:

  1. Its package name is தொடக்கம்.
  2. It contains exactly one zero-argument செயல்பாடு தொடக்கம்().
go run ./cmd/aram run hello.aram

Files and packages

Every source file begins with a package clause. Multiple files with the same package name share declarations:

project/
├── தொடக்கம்.aram
└── helpers.aram
// helpers.aram
தொகுப்பு தொடக்கம்

செயல்பாடு இரட்டி(எ முழுஎண்) முழுஎண் {
    திருப்பு எ * 2
}
// தொடக்கம்.aram
தொகுப்பு தொடக்கம்

செயல்பாடு தொடக்கம்() {
    பதிப்பி(இரட்டி(21))
}

Compile a directory or pass multiple files:

go run ./cmd/aram run project/
go run ./cmd/aram run project/தொடக்கம்.aram project/helpers.aram

Imports and exports

கொணர் imports a package. Names are private unless explicitly marked வெளி; Aram does not use capitalization for visibility.

// math/எண்.aram
தொகுப்பு கணிதம்

வெளி செயல்பாடு கூட்டு(அ முழுஎண், ஆ முழுஎண்) முழுஎண் {
    திருப்பு அ + ஆ
}
தொகுப்பு தொடக்கம்

கொணர் "math"

செயல்பாடு தொடக்கம்() {
    பதிப்பி(கணிதம்.கூட்டு(20, 22))
}

Use a local alias or blank import:

கொணர் க "math"
கொணர் _ "side-effect-package"
Compiler standard library Imports "வலை", "பரிமாற்றம்", and "தரவுத்தளம்" resolve to built-in packages under stdlib/, not relative folders.

Handling operational errors

Networking and HTTP APIs return *வலை.பிழை. Database APIs return *தரவுத்தளம்.பிழை. Success is இன்மை. This is explicit result handling rather than exceptions:

கொணர் "வலை"

இணைப்பு, பிழை := வலை.இணை("127.0.0.1:8080")
எனில் பிழை != இன்மை {
    பதிப்பி(பிழை.செய்தி)
    திருப்பு
}
தள்ளிவை வலை.விடு(இணைப்பு)

Programmer/runtime faults use அலறு and can be intercepted by மீள்() inside a deferred closure. See Panic and recover.

Tamil editor setup

  • Store source as UTF-8.
  • Install Noto Sans Tamil and include it as an editor font fallback.
  • Aram identifiers may mix Unicode letters, marks, digits, and underscore.
  • Both Arabic digits and Tamil digits ௦–௯ work in numeric literals.

Repository-specific font setup is documented in notes/fonts-tamil.md.

For Tamil99 / Inscript / Bamini typing tutors (no phonetic transliteration), see Misc → Tamil typing.
